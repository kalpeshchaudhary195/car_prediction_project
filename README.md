🚗 Car Price Prediction Project

A Machine Learning based Car Price Prediction project that predicts the expected selling price of a car based on its features.

The project contains model training, preprocessing, prediction, and application/API files. Trained machine learning models and preprocessing objects are saved using Pickle so that they can be reused without retraining every time.

📌 Project Overview

The main goal of this project is to build a machine learning system that can estimate the price of a car from its input features.

The project includes:

Data preprocessing

Feature selection

Model training

Feature scaling

Saved machine learning models

Price prediction

Application interface

API-related prediction files

⚙️ Installation

Clone the repository:

git clone <your-github-repository-url>

Move into the project folder:

cd car_prediction_project

Install the required dependencies:

pip install -r requirements.txt

▶️ Run the Project

Run the application

If app.py is the main Streamlit application:

streamlit run app.py

The application will open in your browser.

Run the API

If you want to run the API separately, use the command appropriate for the framework implemented in api.py.

For example, if the API uses FastAPI:

uvicorn api:app --reload

📊 Dataset

The project uses:

car data.csv

The dataset contains information about cars that can be used to learn the relationship between car characteristics and selling price.

The input features depend on the columns available in the dataset and the preprocessing performed in train_model.py.

💾 Saved Machine Learning Files

The project contains three important saved objects:

xgb_model.pkl

Contains the trained XGBoost machine learning model.

scaler.pkl

Contains the scaler used during preprocessing.

columns.pkl

Contains the feature/column information required when making predictions.

These files should be kept consistent with the model and preprocessing code.

🎯 How Prediction Works

User enters/selects car details.

The application receives the input values.

Input features are arranged according to the training columns.

The saved scaler is loaded.

The input is transformed using the same preprocessing used during training.

The saved XGBoost model is loaded.

The model predicts the estimated car price.

The predicted price is displayed to the user.
